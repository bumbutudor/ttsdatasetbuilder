🚀 Quick Start Guide

Creating a TTS Dataset

  1. Create a new project with type "TTS"
  2. Upload PDF or TXT files in "Uploaded Files"
  3. Generate CSV using Spacy or Vision LLM
  4. Record your voice in "Voice Recorder"
  5. Apply TTS normalization
  6. Download your dataset!

Creating an STT Dataset

  1. Create a new project with type "STT"
  2. Upload video files in "Uploaded Files"
  3. Process videos with Whisper in "Video to Dataset"
  4. Apply STT normalization
  5. Clean up using "Cleanse Dataset"
  6. Download your dataset!

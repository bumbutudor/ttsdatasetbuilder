Apply text normalization rules to your dataset for TTS or STT training.

TTS Normalization

Expands abbreviations, converts numbers to words, removes brackets, expands math symbols. Best for Text-to-Speech training.

  • ✓ "dl." → "domnul"
  • ✓ "10" → "zece"
  • ✓ "+" → "plus"
  • ✓ "%" → "la sută"

STT Normalization

Keeps numbers as digits, standardizes quotes and punctuation, removes citations. Best for Speech-to-Text (Whisper) training.

  • ✓ Keeps numbers: "10", "1990"
  • ✓ Standardizes quotes: „text"
  • ✓ Removes [citations]
  • ✓ Fixes spacing

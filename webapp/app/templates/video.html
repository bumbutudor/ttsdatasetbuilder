How it works

  1. Audio is extracted from video files using FFmpeg
  2. Audio is split into segments based on silence detection
  3. Each segment is transcribed using Whisper (Romanian)
  4. Results are saved to metadata.csv with WAV files
Processing large videos may take a while. The server needs to download the Whisper model on first use (~1-2GB).
